a.

Specs are the contract

Specs first, code second. A clear spec is what agents implement against and what I review against — no vibes, no drift.

b.

Humans own the decisions

Agents carry scaffolding, refactors and tests. The reviewer never judges its own work, and acceptance stays mine: no merge, deploy or “Approved” without me.

c.

Guardrails that scale to teams

Hooks that refuse writes to .env and .git, a spec-gate check, and a self-testing sync that rolls itself back. The whole workflow lives in one repo, so a team can run the same one.
